About This Project

Wallpaper Desktop is a collection of two high-performance, interactive animated wallpapers designed for Lively Wallpaper — a popular Windows desktop customization application. This project showcases advanced graphics programming using WebGL and Canvas technologies.

The project features two distinct wallpapers: a WebGL-based fluid simulation implementing real-time Navier-Stokes equations for realistic liquid physics, and a Canvas-based particle system with 7 different visual effects. Both wallpapers are completely zero-dependency, built with pure vanilla JavaScript.

What makes this project special is its audio-reactive capabilities — the fluid wallpaper responds to system audio in real-time, creating mesmerizing visualizations that dance to your music. With 32 total customization options across both wallpapers, users have complete control over colors, effects, physics, and performance settings.

  • Interaction: Mouse attract/repel mode with distance-based forces
  • Customization: 13 options (effect type, count, speed, size, colors, connections)
  • Performance: Configurable 30-120 FPS, up to 500 particles

Code Highlights
Impressive algorithms and patterns implemented in this project:
Navier-Stokes Fluid Simulation
Industry-standard "Stable Fluids" algorithm implementing all 5 core physics steps for realistic liquid behavior.
// 5 Core Physics Steps (GPU Shader Pipeline)
1. Advection      → Semi-Lagrangian particle movement
2. Divergence     → Velocity field compression measurement
3. Pressure       → Jacobi iteration solver (20+ iterations)
4. Curl           → Rotational component extraction
5. Vorticity      → Turbulent swirling force enhancement

// Each step runs as a separate GPU shader program
// Result: Realistic fluid physics at 60 FPS
Double Framebuffer (Ping-Pong) Pattern
Essential GPU optimization pattern that prevents read-after-write conflicts during real-time simulation.
// Prevents GPU read/write conflicts
velocity = {
    read: framebuffer1,   // Read current state
    write: framebuffer2,  // Write new state
    swap() {
        [this.read, this.write] = [this.write, this.read];
    }
};

How to Run
# Method 1: Install in Lively Wallpaper (Recommended)
1. Download and install Lively Wallpaper from Microsoft Store
2. Open Lively Wallpaper application
3. Click "+" button (Add Wallpaper)
4. Navigate to either:
   → fluids-wallpaper/index.html  (for Fluid Simulation)
   → particle-wallpaper/index.html (for Particle Effects)
5. Right-click wallpaper → "Customize" to adjust settings

# Method 2: Test in Browser (No Installation)
1. Navigate to wallpaper folder
2. Double-click index.html
3. Wallpaper opens in browser with full functionality

# Method 3: Development with Live Reload
1. Open folder in VS Code
2. Install "Live Server" extension
3. Right-click index.html → "Open with Live Server"
4. Changes auto-refresh on file save

# Keyboard Shortcuts
Fluids:  C (clear) | R (reset) | S (splat) | Space (burst)
Particles: F (FPS) | R (reset) | 1-7 (switch effect)
