About This Project

NASI is a comprehensive full-stack social media and e-commerce platform that combines the best features of TikTok-style video sharing, Instagram-like social interactions, and Shopify-level e-commerce capabilities into one unified ecosystem. Built with modern technologies and enterprise-grade architecture, NASI demonstrates expertise across backend development, mobile applications, web development, and cloud infrastructure.

This platform enables users to create and share short-form videos, engage with content through likes and comments, participate in live streaming sessions, shop for products seamlessly integrated within the social experience, and interact with other users through threads, stories, and direct messaging. The system is powered by AI-driven content moderation and personalized recommendations to ensure safe and engaging user experiences.

With over 200+ API endpoints, 30+ database tables, and support for millions of concurrent users through scalable architecture, NASI showcases production-ready development practices including Docker containerization, real-time WebSocket communication, distributed caching with Redis, event streaming with Kafka, and cloud-native storage solutions.

How to Run (Localhost)

Prerequisites

  • Backend: Go 1.24+, PostgreSQL 13+, Redis 6+, Docker & Docker Compose
  • Android: Android Studio, JDK 17+, Android SDK 33+, Gradle 8.0+
  • Web: Node.js 18+, npm or yarn

Option 1: Docker Setup (Recommended)

# Navigate to backend directory
cd nasi-main-app/backend

# Start all services with Docker
docker-compose up -d

# Backend runs at:
# - http://localhost:8001 (Docker)
# - PostgreSQL: localhost:5432
# - Redis: localhost:6379
# - Kafka: localhost:9092
# - LiveKit: localhost:7880
# - Owncast: http://localhost:8084

Option 2: Local Development

# 1. Start dependencies only (PostgreSQL & Redis)
cd nasi-main-app/backend
docker-compose up -d postgres_dev redis

# 2. Configure environment variables
cp .env.example .env
# Edit .env with your settings:
# - Database credentials
# - JWT secret key
# - Cloudflare R2 credentials
# - Gmail SMTP settings

# 3. Run backend server
go mod download
go run main.go

# Backend runs at http://localhost:8000

Running Android App

# Navigate to Android directory
cd nasi-main-app/frontendAndroid

# Grant execute permission
chmod +x gradlew

# Fast build (skip tests & lint)
./gradlew assembleDebug -x test -x lint

# Install to connected device/emulator
./gradlew installDebug

# Or open in Android Studio and click Run

# APK output location:
# app/build/outputs/apk/debug/app-debug.apk

Note: Update backend URL in app/build.gradle.kts. For local dev, use http://10.0.2.2:8000/ (Android emulator) or your local IP for physical devices.

Running Web Frontend

# Navigate to web frontend directory
cd nasi-main-app/frontend-web

# Install dependencies
npm install

# Configure environment
cp env.local.example .env.local
# Edit .env.local:
# NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
# NEXT_PUBLIC_WEBSOCKET_URL=ws://localhost:8000/ws/comments

# Start development server
npm run dev

# Web app runs at http://localhost:3000

# Build for production
npm run build
npm run start

Key Environment Variables

# Backend .env configuration
DATABASE_HOST=localhost
DATABASE_USER=postgres
DATABASE_PASSWORD=postgres
DATABASE_NAME=nasi_db

JWT_SECRET=your-secure-jwt-secret-key-32byteslong123

# Cloudflare R2 Storage
R2_ACCOUNT_ID=your-account-id
R2_ACCESS_KEY_ID=your-access-key-id
R2_SECRET_ACCESS_KEY=your-secret-access-key
R2_BUCKET_NAME=your-bucket-name

# Email (Gmail SMTP)
GMAIL_FROM_EMAIL=your-email@gmail.com
GMAIL_APP_PASSWORD=your-gmail-app-password

Testing the Application

# Test backend health
curl http://localhost:8000/

# Test video upload (after login)
curl -X POST http://localhost:8000/api/videos/upload \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "video=@test-video.mp4"

Quick Start Summary

  1. Start backend: docker-compose up -d or go run main.go
  2. Run Android: Build APK and install, or open in Android Studio
  3. Run Web: npm install && npm run dev
  4. Access web at http://localhost:3000
  5. Backend API at http://localhost:8000
