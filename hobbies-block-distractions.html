Block Distractions
Using uBlock Origin Lite Custom Filters
Why Custom Filters?

When I search for something on Google, I want relevant results only. Not shopping suggestions from Shopee or Lazada. Not random social media posts from Instagram or TikTok. Not profiles of people I don't care about.

Using uBlock Origin Lite with custom filters, I remove all these distractions directly from search results. The websites don't even appear - it's like they don't exist. This keeps me super focused on what I'm actually looking for.

The Tool: uBlock Origin Lite
Lightweight Content Blocker

uBlock Origin Lite is the Manifest V3 compatible version of uBlock Origin. It uses declarative content filtering and supports custom filter lists for hiding unwanted elements on web pages.

Features I Use
  • Custom filter rules
  • CSS selector hiding
  • Element picker for new filters
  • Works on all websites
Why uBlock Origin Lite?
  • Works on Chrome (MV3 compliant)
  • Lightweight and fast
  • No performance impact
  • Easy to add custom filters
How to Add Custom Filters
  1. 1 Click on the uBlock Origin Lite extension icon in your browser
  2. 2 Go to Dashboard or Settings
  3. 3 Navigate to My Filters tab
  4. 4 Paste the custom filter rules and click Apply Changes
Filter 1: Block Shopee & Lazada in Google Shopping
Remove Shopping Distractions

When I search on Google Shopping tab, I don't want to see results from Shopee or Lazada. These filters hide all products from these platforms. 

! Block Shopee in Google Shopping
google.com##.sh-dgr__grid-result:has(a[href*="shopee"])
google.com##.sh-dgr__content:has(a[href*="shopee"])
google.com##.sh-pr__product-results-grid .sh-dgr__gr-auto:has(a[href*="shopee"])
google.com##div[data-docid*="shopee"]
google.com##.sh-np__click-target:has([href*="shopee"])
google.com##.sh-pr__product-results .sh-dlr__list-result:has(a[href*="shopee"])

! Block Lazada in Google Shopping
google.com##.sh-dgr__grid-result:has(a[href*="lazada"])
google.com##.sh-dgr__content:has(a[href*="lazada"])

Remove Social Media Posts from Image Search

Filter 3: Remove "Profiles" Section from Google Search
Hide People Profiles in Search Results

Google sometimes shows a "Profiles" section with social media accounts of people. This is distracting when you're searching for information, not people. 

! Remove "Profiles" section from Google Search Results
google.com##div:has(> div > div > span:has-text(/^Profiles$/))
google.com##div[data-hveid]:has(span:has-text(/^Profiles$/))
google.com##.g:has(h2:has-text(/Profiles/))
google.com##div.ULSxyf:has(span:has-text(/^Profiles$/))
google.com###rso > div:has(span:has-text(/^Profiles$/))

Bonus: Windows Hosts File Blocking
System-Level Website Blocking

For websites I want to block completely (not just hide from search results), I use the Windows hosts file. This blocks the website at the system level — it won't load in any browser or application.

How It Works

The hosts file maps domain names to IP addresses. By pointing a domain to 0.0.0.0 or 127.0.0.1, the website becomes unreachable.

Location: C:\Windows\System32\drivers\etc\hosts
Example Hosts File Entries
# Block Social Media
0.0.0.0 facebook.com
0.0.0.0 www.facebook.com
0.0.0.0 instagram.com
0.0.0.0 www.instagram.com
0.0.0.0 tiktok.com
0.0.0.0 www.tiktok.com
0.0.0.0 twitter.com
0.0.0.0 www.twitter.com
0.0.0.0 x.com
0.0.0.0 www.x.com

# Block Shopping Distractions
0.0.0.0 shopee.com.my
0.0.0.0 www.shopee.com.my
0.0.0.0 lazada.com.my
0.0.0.0 www.lazada.com.my

# Block Time Wasters
0.0.0.0 reddit.com
0.0.0.0 www.reddit.com
0.0.0.0 9gag.com
0.0.0.0 www.9gag.com
How to Edit Hosts File
  1. 1. Open Notepad as Administrator
  2. 2. File → Open → Navigate to hosts file
  3. 3. Add your blocking entries
  4. 4. Save the file
  5. 5. Flush DNS: ipconfig /flushdns
Why Use Hosts File?
  • • Works across ALL browsers
  • • Works on ALL applications
  • • No extensions needed
  • • Harder to bypass than browser blockers
  • • Survives browser reinstalls
Pro Tips
Use Element Picker

Right-click on uBlock Origin Lite icon and select "Element Picker" to create new filters for any element on any page.

Test Your Filters

After adding filters, refresh the page and search to verify the unwanted content is hidden.

Add More Sites

You can modify these filters to block any website. Just replace "shopee" or "lazada" with any domain you want to hide.

Backup Your Filters

Export your custom filters regularly so you don't lose them when reinstalling the browser.
