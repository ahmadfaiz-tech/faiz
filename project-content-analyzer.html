Content Analyzer
Analyze content using AI
About This Project

Content Analyzer is a production-ready, enterprise-grade AI platform for comprehensive media analysis built with a hybrid architecture combining Python (for ML/AI processing) and Rust (for high-performance API gateway). This system leverages state-of-the-art machine learning models to analyze images, videos, and audio content, providing intelligent categorization, content understanding, and recommendation capabilities for social media platforms and content management systems.

The platform integrates multiple cutting-edge AI models including CLIP for zero-shot classification, BLIP-2 for image captioning, YOLOv8 for object detection, Whisper for speech-to-text, and Ollama (Qwen2.5:14b) for advanced content summarization. With support for PaddleOCR, EasyOCR, and Pytesseract, the system implements a robust multi-engine OCR fallback strategy that handles 100+ languages with exceptional accuracy.

Built specifically for integration with the NASI social media platform, Content Analyzer provides TikTok-style engagement metrics, viral velocity tracking, real-time recommendations, and comprehensive content moderation including NSFW detection and violence classification. The system features a sophisticated worker pool architecture with 18-24 concurrent workers, parallel frame processing, and advanced caching mechanisms.

⚡ Performance Note: This system is hardware-optimized and performance scales dramatically with available resources. With minimum hardware (4 cores, 8GB RAM, CPU only), processing takes ~8-10 minutes for 30 video frames. However, with recommended hardware (24-core CPU, 128GB RAM, NVIDIA RTX 4090 GPU), the same task completes in just 3-5 seconds — a 100-160x performance improvement. Performance depends on CPU cores, RAM capacity, and GPU acceleration capabilities.

⚡ Performance Characteristics

🔴 CRITICAL: Performance is Hardware-Dependent

This system's performance scales dramatically with available hardware resources. The same 30-frame video analysis task can take anywhere from 8-10 minutes on minimum hardware to just 3-5 seconds on recommended hardware — a difference of up to 160x in speed. GPU acceleration alone provides 2x speed boost, while parallel processing and high-core CPUs multiply this further.

💻 Minimum Configuration

CPU: 4 cores
RAM: 8GB
GPU: None (CPU fallback mode)
Storage: 20GB for models

Performance:

• 30 video frames: ~8-10 minutes

• Single image: ~5-8 seconds

• Limited parallelization

• CPU-only OCR (slower)

🚀 Recommended Configuration

CPU: Intel i9-14900HX (24 cores, 32 threads)
RAM: 128GB DDR5-5600
GPU: NVIDIA RTX 4090 (8GB VRAM)
Storage: NVMe SSD (50GB recommended)

Performance:

• 30 video frames: 3-5 seconds (100-160x faster!)

• Single image: <2 seconds

• Full parallelization (20 frames concurrently)

• GPU-accelerated OCR with TensorRT

🔧 Performance Optimizations Implemented

Worker Pool Optimization

18-24 concurrent workers utilizing 75% of CPU cores for optimal throughput without system overload.

Parallel Frame Processing

Processes 20 video frames concurrently using Tokio async runtime for maximum parallelization.

GPU Acceleration

PaddleOCR with TensorRT optimization and FP16 precision provides 2x speed boost on RTX GPUs.

Frame Caching

In-memory LRU cache for up to 100 frames, utilizing 128GB RAM for instant retrieval.

Batch Inference

Processes multiple images/frames in batches (batch_size=8-32) for improved GPU utilization.

Model Caching

Pre-loaded models in memory eliminate initialization overhead for subsequent requests.

💡 Key Takeaway

Performance is NOT a fixed attribute of this system — it is directly proportional to hardware capabilities:

  • CPU Cores: More cores = more parallel workers = faster batch processing
  • RAM Capacity: More RAM = larger frame cache = reduced I/O bottlenecks
  • GPU Acceleration: NVIDIA GPU with TensorRT = 2x baseline speed boost for OCR and inference
  • Storage Speed: NVMe SSD = faster model loading and video frame extraction

The 100-160x performance difference demonstrates how hardware-optimized architecture can transform the same codebase from "slow" to "lightning-fast."

How to Run (Localhost)

System Requirements

  • OS: Windows, Linux, macOS
  • Python: 3.9+ (3.12 recommended)
  • Rust: 1.70+ (latest stable)
  • PostgreSQL: 14+
  • Redis: Latest stable
  • RAM: 8GB minimum, 128GB recommended
  • CPU: 4+ cores (24 cores optimal)
  • GPU: NVIDIA RTX series with CUDA (optional but recommended)
  • Storage: 20GB minimum for models, 50GB recommended

Option 1: Automated Setup (Windows - Recommended)

# Navigate to project directory
cd contentanalysis

# Run automated setup script
setup.bat

# This script will:
# - Create Python virtual environment
# - Install all Python dependencies
# - Download required ML models
# - Setup PostgreSQL database
# - Build Rust API
# - Configure environment variables

Option 2: Manual Setup (All Platforms)

# 1. Create Python virtual environment
python -m venv venv312

# Activate virtual environment
# Windows:
venv312\Scripts\activate
# Linux/Mac:
source venv312/bin/activate

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Setup PostgreSQL database
createdb content_analysis_db

# 4. Build Rust API
cd rust-api
cargo build --release
cd ..

# 5. Configure environment
cp .env.example .env
# Edit .env with your settings

Environment Configuration

# Database Configuration
DATABASE_URL=postgresql://postgres:password@localhost/content_analysis
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_NAME=content_analysis_db

# Redis Configuration
REDIS_URL=redis://127.0.0.1/

# AI Model Configuration
OLLAMA_ENABLED=true
OLLAMA_MODEL=qwen2.5:14b
ANTHROPIC_API_KEY=your_key_here  # Optional

# Performance Settings (adjust based on your hardware)
WORKER_POOL_SIZE=20              # 75% of your CPU cores
MAX_PARALLEL_FRAMES=20           # Concurrent frame processing
PADDLE_OCR_USE_GPU=true          # Enable GPU acceleration
PADDLE_OCR_GPU_MEM=8000          # GPU memory allocation (MB)

⚙️ Performance Tuning: Adjust WORKER_POOL_SIZE and MAX_PARALLEL_FRAMES based on your CPU cores. For optimal performance, use 75% of available cores.

Starting the Services

Start All Services (Recommended)

# Windows
start_services.bat

# Linux/Mac
./start_services.sh

# This will start:
# - Python ML API on port 8088
# - Rust API Gateway on port 8089
# Both services run concurrently

Start Services Separately

# Terminal 1: Start Python ML API (port 8088)
python src/main.py server --port 8088
# Or using uvicorn directly:
uvicorn src.api.endpoints:app --host 0.0.0.0 --port 8088 --reload

# Terminal 2: Start Rust API Gateway (port 8089)
cd rust-api
cargo run --release
# Or run the binary directly:
./target/release/rust-api

CLI Usage (Without API)

# Analyze single image
python src/main.py analyze --path "path/to/image.jpg"

# Analyze single video
python src/main.py analyze --path "path/to/video.mp4"

# Batch analyze directory
python src/main.py batch --path "media_folder" --output results.json

# Analyze with specific output format
python src/main.py analyze --path "video.mp4" --format json
