Automated Diagram Generation
Creating Clean, Scalable Diagrams with Graphviz
Why Code-Based Diagrams?

Traditional diagramming tools require manual placement of nodes and edges, which becomes tedious for complex systems and makes updates time-consuming. Code-based diagram generation with Graphviz solves these problems by allowing you to describe relationships in a simple text format, with the layout algorithm handling the visual arrangement automatically.

I use Graphviz extensively for creating system architecture diagrams, workflow visualizations, database schemas, and data structure representations. This approach ensures diagrams are version-controllable, easily reproducible, and can be generated programmatically from actual code or configuration files.

What is Graphviz?

Graphviz (Graph Visualization Software) is an open-source package for drawing graphs specified in DOT language scripts. It provides several layout programs that automatically arrange nodes and edges to create clean, readable diagrams.

Key advantages of Graphviz include:

  • Automatic Layout: Algorithms handle node positioning for optimal readability
  • Multiple Output Formats: Export to PNG, SVG, PDF, and many other formats
  • Version Control Friendly: Text-based source files work perfectly with Git
  • Scriptable: Generate diagrams programmatically from any language
  • Consistent Styling: Define styles once and apply across all diagrams
DOT Language Example
digraph SystemArchitecture {
    // Graph styling
    rankdir=TB;
    node [shape=box, style=filled, fillcolor="#34D399"];

    // Define nodes
    Client [label="Web Client", fillcolor="#60A5FA"];
    API [label="REST API\n(Node.js)"];
    Auth [label="Auth Service"];
    DB [label="PostgreSQL", shape=cylinder];
    Cache [label="Redis Cache", shape=cylinder, fillcolor="#F87171"];

    // Define relationships
    Client -> API [label="HTTPS"];
    API -> Auth [label="JWT Validation"];
    API -> DB [label="Queries"];
    API -> Cache [label="Session Data"];
    Auth -> DB [label="User Lookup"];
}

This DOT code generates a clean system architecture diagram with automatic node positioning.

Graphviz Layout Engines
dot

Hierarchical layouts for directed graphs. Best for flowcharts and organization charts.

neato

Spring model layouts for undirected graphs. Great for network topologies.

fdp

Force-directed placement. Good for large undirected graphs.

sfdp

Scalable force-directed. Handles graphs with thousands of nodes.

circo

Circular layout. Perfect for cyclic structures and rings.

twopi

Radial layout. Ideal for hierarchies with a central root.

Programmatic Generation Example
from graphviz import Digraph

def generate_architecture_diagram(services, connections):
    dot = Digraph('Architecture', format='svg')
    dot.attr(rankdir='LR', bgcolor='transparent')
    dot.attr('node', shape='box', style='filled', fillcolor='#34D399')

    # Add service nodes
    for service in services:
        dot.node(service['id'], service['name'])

    # Add connections
    for conn in connections:
        dot.edge(conn['from'], conn['to'], label=conn.get('protocol', ''))

    # Render to file
    dot.render('architecture', cleanup=True)

# Usage
services = [
    {'id': 'api', 'name': 'API Gateway'},
    {'id': 'auth', 'name': 'Auth Service'},
    {'id': 'db', 'name': 'Database'}
]
connections = [
    {'from': 'api', 'to': 'auth', 'protocol': 'gRPC'},
    {'from': 'auth', 'to': 'db', 'protocol': 'SQL'}
]

generate_architecture_diagram(services, connections)
