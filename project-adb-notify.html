ADB Notify App
Easily connect android devices
About This Project

ADB Notify App is a lightweight Android application designed to receive broadcast intents from ADB (Android Debug Bridge) commands and display custom notifications on an Android device. The primary purpose is to enable developers to send notifications to their phone from a computer via ADB without the notification appearing as coming from the shell/ADB system itself.

The app provides a simple bridge between ADB commands on a development machine and user-facing notifications on an Android phone. It includes smart wireless connection tools with automatic network scanning, device fingerprinting, and multiple fallback mechanisms for reliable notification delivery.

Key Benefit: Developers can trigger custom notifications on their Android device remotely via command line, useful for build completion alerts, debugging feedback, automated testing notifications, and more.

Features
Multiple Notification Delivery Methods
  • BroadcastReceiver Method - Most reliable for background notifications
  • Service Method - Background service with foreground notification
  • Activity Method - Direct activity-based notification handler
  • Automatic fallback mechanisms if primary method fails
Rich Notification Features
  • Custom messages with full text display (BigTextStyle)
  • Notification channels support (Android 8.0+)
  • Vibration, LED indicators, and sound alerts
  • Tap-to-open functionality
  • Color-coded notifications for each method
  • Public visibility (lockscreen display)
Wireless ADB Connection Tools
  • Automatic network scanning for Android devices
  • Smart device fingerprinting to identify specific phones
  • Wireless debugging support without USB cable
  • Network profile detection and memory
  • IP range optimization for faster scanning
Permission & Cross-Version Support
  • POST_NOTIFICATIONS permission handling (Android 13+)
  • Foreground service and wake lock permissions
  • Runtime permission checking
  • Supports Android 8.0 (API 26) to Android 14 (API 34)
Debugging & Automation
  • Comprehensive system logging for debugging
  • Toast messages for user feedback
  • Batch scripts for Windows automation
  • Node.js scripts for smart connection
  • Multiple test scripts for each notification method

How to Run
Prerequisites
  • Android SDK installed
  • Java 8 or higher
  • Gradle (included via wrapper)
  • ADB installed and in PATH
  • Android device with USB debugging enabled
  • Node.js (for wireless connection scripts)
Build and Install
# Clean build
./gradlew.bat clean build

# Install on connected device
./gradlew.bat installDebug

# Or use quick test script
quick-test.bat

# Run the app
adb shell am start -n com.example.adbnotif/.MainActivity
Send Test Notifications
# Via Broadcast (Recommended)
adb shell am broadcast -a com.example.adbnotif.SHOW_NOTIFICATION \
    --es message "Your message here"

# Via Activity
adb shell am start -n com.example.adbnotif/.NotificationActivity \
    -a com.example.adbnotif.SHOW_NOTIFICATION \
    --es message "Your message here"

# Via Service
adb shell am startservice -n com.example.adbnotif/.NotificationService \
    -a SHOW_NOTIFICATION --es message "Your message here"
Wireless Connection (No USB)

1. Enable Wireless Debugging on phone (Settings → Developer Options)

2. Run connection script:

connect.bat          # Universal connection
# OR
node final-connect.js

3. The script will auto-detect, scan network, and connect to your device
