About This Project

DuitNow QR Scanner App is a React Native mobile application that simulates a complete CIMB Bank DuitNow payment flow with real-time QR code scanning capabilities. This project demonstrates modern mobile development practices and professional banking interface design for Android devices.

The app features a complete 5-screen payment journey - from homepage to QR scanning, amount entry, transaction approval, and final receipt. It includes smart data extraction using an EMVCo TLV parser that automatically extracts merchant names from DuitNow QR codes following Malaysia's PayNet standard.

Note: This is a frontend prototype/learning project. No actual payments are processed and no connection to real banking APIs is made.

Features
QR Code Scanning
  • Live camera scanning with custom overlay frame and centering guides
  • Scan from gallery images (JPEG support)
  • Real-time QR code detection and validation
  • Automatic merchant name extraction from QR data
Smart Data Extraction
  • EMVCo TLV parser for DuitNow QR codes
  • Extracts merchant name from tag 59 (Merchant Name field)
  • Handles standard PayNet/DuitNow QR format
  • Regex-based pattern matching for reliable parsing
Complete 5-Screen Payment Flow
  • Homepage - Landing page with "Imbas QR" (Scan QR) button
  • Camera - Full-screen camera view with Pay/Transfer toggle and scan frame overlay
  • Put Amount - Amount entry with automatic MYR currency formatting
  • Approve - Confirmation screen with transaction details and SecureTAC button
  • Output - Success receipt with OCTO reference number and timestamp
Currency & Transaction Features
  • Automatic decimal placement (e.g., "100" → "1.00")
  • Real-time input validation with MYR (Malaysian Ringgit) format
  • Transaction logging to local storage
  • 9-digit OCTO reference number generation
UI/UX Features
  • Real-time clock display (updates every second)
  • Linear gradient backgrounds with professional banking look
  • Material Icons integration
  • Custom Calibri font family
  • Malay language interface ("Imbas QR", "DuitNow QR", etc.)

How to Run (Localhost)
Prerequisites
  • Node.js >= 18
  • React Native development environment (Setup Guide)
  • Android SDK (API 31+)
  • Android device or emulator with camera support
  • Git
# 1. Clone the repository
git clone https://github.com/ahmadfaiz-tech/qrscanner-app.git
cd QrScannerApp

# 2. Install dependencies
npm install

# 3. Link custom Calibri fonts to Android
npx react-native-asset

# 4. Start the Metro bundler (Terminal 1)
npm start

# 5. Run on Android device/emulator (Terminal 2)
npm run android

Key Implementation: EMVCo TLV Parser

The app includes a custom parser for extracting merchant names from DuitNow QR codes following the EMVCo QR code standard using TLV (Tag-Length-Value) format:

const extractFullName = (qrData: string): string => {
  // Tag 59 = Merchant Name (EMVCo standard field)
  const nameField = qrData.match(/59(\d{2})/);
  if (nameField) {
    const length = parseInt(nameField[1], 10);
    const startIndex = nameField.index! + 4;
    const merchantName = qrData.substring(startIndex, startIndex + length);
    return merchantName;
  }
  return 'Nama tidak ditemui';
};

QR Data: ...5924KAFETERIA D SELERA BONDA6002MY...

Parsed: Tag 59, Length 24, Value KAFETERIA D SELERA BONDA
