Fix Windows Defender
Resolving "Page IT Not Available" and Security Issues
The Problem

A common and frustrating issue in Windows is when Windows Security shows "Page IT Not Available" or the Virus & Threat Protection section becomes inaccessible. This typically occurs due to corrupted registry entries, Group Policy conflicts, or the AllowUserUIAccess policy blocking the UI.

I've developed an automated batch script that systematically fixes this issue by addressing all potential causes in the correct order.

Common Root Causes
Policy Manager Blocking UI

The registry key AllowUserUIAccess in Policy Manager is set to block access to Windows Security interface.

Corrupted Registry Entries

Windows Defender policies in HKLM\SOFTWARE\Policies\Microsoft\Windows Defender are corrupted or misconfigured.

Group Policy Conflicts

"Hide the Virus and threat protection area" policy is enabled, preventing access to security settings.

Windows Security App Issues

The SecHealthUI app itself is corrupted or needs to be reset/repaired.

The Fix (Automated Script)

I created a batch script that automates all the necessary steps to fix this issue:

Step 1: Delete Windows Defender Registry Folder

Remove all policy configurations including the problematic Policy Manager subfolder.

reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender" /f

:: PowerShell fallback if reg command fails
powershell -Command "Remove-Item -Path 'HKLM:\SOFTWARE\Policies\Microsoft\Windows Defender' -Recurse -Force"
Step 2: Reset Windows Security App

Terminate, repair, and reset the SecHealthUI application.

:: Terminate running instances
taskkill /f /im SecHealthUI.exe

:: Repair the app
powershell -Command "Get-AppxPackage Microsoft.SecHealthUI -AllUsers | Foreach {Add-AppxPackage -DisableDevelopmentMode -Register \"$($_.InstallLocation)\AppXManifest.xml\"}"

:: Reset app settings
powershell -Command "Get-AppxPackage *Microsoft.SecHealthUI* | Reset-AppxPackage"
Step 3: Configure Group Policy

Reset the "Hide the Virus and threat protection area" policy to Not Configured.

:: Delete Security Center policies to reset to Not Configured
reg delete "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center" /f
reg delete "HKCU\SOFTWARE\Policies\Microsoft\Windows Defender Security Center" /f
Step 4: Force Group Policy Update

Apply all policy changes immediately.

gpupdate /force
Additional Cleanup

The script also performs these additional steps for a thorough fix:

  • Stops and restarts Windows Defender services (WinDefend, SecurityHealthService, wscsvc)
  • Clears Windows Defender cache files
  • Re-registers Windows Security components
  • Refreshes Windows Explorer
  • Verifies the fix was successful
Important Notes
  • Run as Administrator: The script requires elevated privileges to modify registry and system settings.
  • Restart Recommended: For best results, restart your computer after running the fix.
  • Save for Future Use: Keep the .bat file handy as the issue may return after certain Windows updates.
  • Backup First: Consider creating a system restore point before running any registry modifications.
